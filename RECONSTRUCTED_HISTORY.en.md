# Reconstructed History Notice

The V1.0.0 through V6.6.0 history in this repository was reconstructed on 2026-08-31 from official release ZIP archives retained locally.

- These commits are not the original development commits and do not claim to reproduce the actual historical development sequence.
- Reconstruction commits are divided along explainable boundaries such as Skills, Reviewers/Agents, Runtime/Hooks, installation scripts, tests, documentation, and release metadata.
- Commit and tag timestamps record the reconstruction time. Original file timestamps are archival evidence only and are not used as Git commit timestamps.
- Each version tag identifies the complete sanitized public snapshot for that release.
- Personal-directory examples in validation scripts from V3.0.0, V3.1.0, and V3.2.0 were replaced with neutral test directories.
- Shared template branches and external references unrelated to Codex were removed from the public V4.0.0 through V4.2.0 trees.
- Original ZIP archives remain unchanged, are stored locally only, are not committed to Git, and are not uploaded as public Release assets.
- `RELEASE_ARCHIVES.md` records each original ZIP SHA-256, public-tree digest, and sanitization count.
