# Reconstructed History Notice

The V1.0.0 through V6.6.0 history in this repository was reconstructed on
2026-08-31 from locally preserved official release ZIP archives.

- These commits are not the original development commits and do not claim the original development order.
- Reconstruction commits are split into explainable Skill, Reviewer/Agent, Runtime/Hook, installer/tooling, test, documentation, and release-metadata boundaries.
- Commit and tag timestamps are reconstruction timestamps. Original file timestamps are archive evidence only.
- Each version tag represents the complete public sanitized snapshot for that release.
- Personal directory examples in the V3.0.0, V3.1.0, and V3.2.0 validation scripts were replaced with neutral test paths.
- Shared-template branches and external references unrelated to Codex were removed from the public V4.0.0 through V4.2.0 trees.
- Original ZIP archives remain unchanged and local. They are not committed or uploaded as public release assets.
- `RELEASE_ARCHIVES.md` records each original archive SHA-256, public tree digest, and sanitization count.
