# TaskOutcomeEvent V3

V3 只记录生命周期、项目隔离、批准派发档位、permit 引用、预留成本和结果指标。它不读取、推断、保存或导出宿主实际模型身份与推理强度。

## 写入边界

- 新链只能写入 V3；V2 链保持不可变并使用独立路径只读校验。
- `metadata` 递归删除模型身份、推理强度、Prompt、响应、代码、Diff、凭据和秘密字段。
- 同一链不得混用 V2 与 V3。
- `project_id + repo_fingerprint` 不一致时失败关闭。

## 旧链投影

V2 原始记录先按原始 schema、SHA-256 与可选 HMAC 校验。随后只投影生命周期、项目身份、终态和审查计数；旧模型身份字段及其嵌套副本不得进入 Snapshot、Proposal、验证报告或发布证明。

## 权限

事件只证明观察事实，不授予修改、提交、推送、部署、重启、数据写入或 Proposal 执行权限。
