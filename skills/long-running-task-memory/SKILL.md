# 长期任务外部记忆与持续检查点技能

## 执行原则

1. 先读取 `references/long-running-task-memory-rules.md` 索引，只加载当前阶段需要的记忆分片。
2. 对话上下文和子 Agent 上下文都是易失工作区；任务控制状态、授权、证据和下一步必须持久化到仓库外的 Agent 专用目录。
3. 至少维护 `CURRENT_TASK.md` 和 `PROGRESS.md`；多步骤任务同时维护 `PLAN.md` 和任务执行信封。
4. 每完成一个可独立恢复节点立即写检查点；连续 5 个实质动作仍未成节点时写“进行中检查点”。
5. 高风险操作前后双检查点；上下文压缩、会话切换或暂停前刷新 `HANDOFF.md`。
6. 多 Agent 使用单一写入者：主协调 Agent 更新共享记忆；独立上下文子 Agent 只返回结构化结果或写被分配的独立报告。
7. 恢复时核对当前消息、任务信封、最近检查点、代码、配置、Git 和运行状态；文档不能覆盖实际事实。
8. 记忆写入前后执行凭据扫描、权限检查和生命周期治理。

## 工具

- 检查点与安全治理：`scripts/checkpoint.py`
- 任务信封与证据有效性由 `$engineering-quality-delivery` 的 `execution_guard.py` 管理。

## 边界

- 外部记忆不得进入项目仓库、Git、项目 CHANGELOG 或正式工程文档。
- 不记录冗长内部推理，只记录可验证事实、证据等级、授权、状态、阻塞、风险和下一步。
