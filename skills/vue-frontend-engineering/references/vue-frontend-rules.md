# Vue 前端工程规则

> 当前任务涉及 Vue、前端页面、交互、构建或浏览器行为时加载。必须先识别 Vue 和构建工具版本，不得把 Vue 3 写法机械套用到 Vue 2 项目。

## 一、版本与项目识别

确认：

- Vue 2 / Vue 3；
- Options API / Composition API；
- JavaScript / TypeScript；
- Vuex / Pinia；
- Vue Router 版本；
- Vite / Vue CLI / Webpack；
- npm / pnpm / yarn 及锁文件；
- UI 组件库、浏览器兼容目标和部署基础路径。

以 `package.json`、锁文件、构建配置、入口文件和实际运行环境为准。未经要求不得升级 Vue、构建工具、UI 组件库或全量重写 Composition API。

---

## 二、组件与状态边界

组件应保持单一职责，区分：

- 页面容器和业务组件；
- 展示组件和通用组件；
- API 请求、状态管理和视图渲染；
- 局部状态、跨组件状态和服务端状态。

主动检查：

- Props 是否被直接修改；
- Emits / 事件契约是否明确；
- 组件卸载后定时器、监听器、SSE、WebSocket 和请求是否清理；
- Watch 是否产生循环更新、重复请求或隐式副作用；
- 计算属性是否执行异步或写操作；
- KeepAlive、缓存页面和路由复用是否导致旧状态残留；
- Vuex / Pinia 是否存储不可序列化、过大或敏感对象。

不得把所有状态放入全局 Store，也不得用全局事件总线规避清晰的数据流。

---

## 三、接口、异步和状态一致性

接口调用必须处理：

- 正常、加载、空、错误、禁用和部分成功状态；
- 超时、取消、重试和重复点击；
- 页面切换、组件卸载和请求竞态；
- 旧请求晚于新请求返回导致覆盖；
- Token 失效、权限不足和统一错误处理；
- 前后端字段、枚举、时间、金额和错误码契约。

对搜索联想、分页切换和快速筛选等场景，使用防抖、取消、请求序号或最新结果校验，避免异步竞态。

非幂等请求禁止盲目自动重试。提交按钮应防重复，但不能仅依赖前端防重复，后端仍需幂等和权限校验。

---

## 四、路由、权限和安全

前端菜单、按钮和路由守卫只改善用户体验，不能代替后端权限。

检查：

- 未登录、Token 过期和刷新；
- 动态路由和权限路由残留；
- 水平和垂直越权入口；
- 路由参数、查询参数和重定向白名单；
- 敏感信息是否进入 URL、LocalStorage、日志和错误上报；
- `v-html`、富文本、URL、文件名和下载链接的 XSS 风险；
- CSRF、CORS、Cookie 属性和 iframe 风险。

不得在前端保存密码、密钥和服务端 Secret。不得把后端返回内容未经清洗直接插入 HTML。

---

## 五、SSE、WebSocket 和实时交互

检查：

- 建立、重连、心跳、超时和关闭；
- 页面切换和组件卸载释放；
- 重复连接、重复消息和消息顺序；
- 半截消息、断线恢复和最后事件位置；
- 服务端任务继续执行与客户端取消；
- 多标签页、浏览器休眠和网络切换；
- 消息落库、刷新恢复和前后端最终一致性。

不能只让连接保持不断开，还要确保刷新后可恢复、不会重复展示、不会泄漏连接和定时器。

---

## 六、表单、列表和文件

### 6.1 表单

检查：

- 初始值、清空、回显和编辑状态；
- 必填、长度、数值、金额、时间和跨字段校验；
- 提交中禁用、重复点击和失败后恢复；
- 前端校验与后端校验口径；
- 敏感字段自动填充和浏览器缓存。

### 6.2 列表和分页

检查：

- 空列表、加载更多、深分页和总数变化；
- 筛选后页码重置；
- 排序字段白名单；
- 行 Key 稳定性；
- 大列表虚拟滚动和图片懒加载；
- 批量选择在分页、刷新和过滤后的状态。

### 6.3 文件上传下载

检查大小、类型、扩展名、分片、断点、进度、取消、重试、重复文件、临时状态和下载文件名编码。

前端文件限制只能作为体验层，后端和存储仍需独立校验。

---

## 七、性能和资源

主动检查：

- 重复渲染、深度 Watch 和大对象响应式；
- 大列表、图片、视频和预览资源；
- 路由分包、按需加载、Tree Shaking 和包体积；
- 重复 API 请求、缓存失效和内存泄漏；
- 长任务阻塞主线程；
- 日志、埋点和错误上报风暴。

复杂计算可评估 Web Worker，但不得为了简单逻辑增加维护成本。性能结论应有构建产物、浏览器性能数据或可复现对比支持。

---

## 八、构建、环境和部署

检查：

- 环境变量是否区分构建时和运行时；
- `.env` 是否包含敏感信息；
- API Base URL、静态资源路径和反向代理；
- Source Map 是否在生产安全暴露；
- 缓存文件名、CDN 和旧资源兼容；
- 构建警告、依赖漏洞和浏览器兼容；
- Nginx History 路由回退和缓存策略。

不得修改全局 npm 配置、锁文件或大版本依赖而不说明原因和影响。

---

## 九、最低验证

只要修改前端运行行为，至少执行项目正式生产构建：

```bash
npm run build
```

如果项目使用 pnpm、yarn 或其他脚本，执行项目实际命令。

根据修改范围验证：

- 正常、加载、空、错误、禁用状态；
- 重复点击、刷新、路由切换和权限不足；
- 接口超时、失败和异步竞态；
- 响应式布局和目标浏览器；
- SSE / WebSocket 断开和恢复；
- 文件上传下载；
- 前后端字段和状态一致性。

构建通过不代表交互验证完成，静态代码检查也不能代替浏览器运行验证。

---

## 十、Vue 代码审查附加清单

除通用六维复审外，检查：

- 组件生命周期和资源释放；
- Props、Emits、Watch、Computed 和 Store 边界；
- 请求竞态、取消、重复提交和错误恢复；
- 路由守卫、动态路由和权限残留；
- XSS、敏感数据和不安全 URL；
- 大列表、包体积、内存和重复请求；
- Vue 2 / Vue 3、构建工具和浏览器兼容；
- 页面刷新、新旧前端灰度和缓存资源兼容。
