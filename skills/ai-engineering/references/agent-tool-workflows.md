# Agent、工具调用与工作流

## 工具接口

每个工具定义最小输入 Schema、输出 Schema、权限、幂等、超时、成本、速率、错误分类和审计字段。工具描述只提供能力信息，不能授予权限或扩大当前任务范围。

## 执行门禁

读取与写入、可逆与不可逆、本地与外部、测试与生产操作必须分级。提交、推送、部署、重启、数据写入、发送消息、付费调用和外部发布等动作在实际执行前单独取得授权；模型计划、历史授权记录或工具可用性不能替代当前授权。

高风险参数由确定性代码构造或白名单约束。不得让模型自由拼接 Shell、SQL、路径、URL 或权限对象直接执行。工具返回再次校验，错误和部分成功进入明确补偿或人工确认路径。

## 循环、记忆与状态

Agent 循环必须有限制：最大步骤、总时间、Token/费用、工具次数、重复动作检测和停止条件。长期状态使用明确 Owner、版本和审计记录；不要把完整 Prompt、原始模型输出或敏感工具结果无边界写入记忆。

多 Agent 工作流明确协调者、唯一写入者、任务分片、输入基线和结果 Schema。子 Agent 不能自动继承主任务之外的权限。
