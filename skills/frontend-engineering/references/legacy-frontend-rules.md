# 原生 JavaScript、jQuery、Layui、JSP 与传统前端专项规则

> 在无现代框架、服务端模板、jQuery/Layui、JSP、传统多页应用或历史插件项目中加载，并与 `frontend-core-rules.md` 共同使用。不得因为代码旧就擅自重写为现代框架。

## 一、项目和加载顺序

确认：

- 原生脚本、jQuery、Layui、JSP/模板引擎和插件版本；
- `<script>` 加载顺序、全局变量、AMD/CMD 或传统模块方式；
- 浏览器兼容目标、Polyfill 和静态资源缓存；
- 页面由服务端渲染还是 Ajax 动态更新；
- 后端返回结构、字符编码和下载响应。

历史依赖可能通过全局变量、反射式调用或页面顺序间接使用，不能仅凭静态搜索删除。

## 二、DOM、事件和全局状态

检查：

- 重复绑定、事件委托、解绑和动态 DOM；
- 页面局部刷新后旧 Handler、定时器和插件实例是否残留；
- 全局变量、命名冲突和跨页面状态污染；
- DOM 查询、循环操作、布局抖动和大列表性能；
- 插件初始化/销毁、重复实例和版本兼容；
- 内联事件、字符串执行和动态脚本。

对动态列表优先使用稳定的事件委托，但必须避免重复注册和无法解绑。

## 三、Ajax、回调和竞态

检查：

- 回调嵌套、错误分支、超时、取消和重复提交；
- 页面切换或弹窗关闭后回调继续修改已销毁 DOM；
- 多次查询返回顺序和旧结果覆盖；
- 全局 Ajax 拦截器和 Token 失效处理；
- 表单序列化、字符编码、日期、金额和空值；
- 服务端 HTML 片段和 JSON 字段的契约兼容。

不得通过同步 Ajax 阻塞浏览器主线程。

## 四、Layui、JSP 和服务端模板

检查：

- Layui 模块加载、表格 reload、表单 render、弹层关闭和事件重复绑定；
- JSP/模板输出的 HTML、JavaScript 字符串和 URL 是否正确转义；
- 服务端变量直接拼入脚本导致的 XSS、引号和编码问题；
- 页面、Servlet/Controller、下载流和响应头兼容；
- 旧页面缓存、静态资源版本和浏览器回退。

前端隐藏按钮不能替代 Struts/Spring/Servlet 等后端权限校验。

## 五、安全和渐进改造

- 禁止将不可信内容直接写入 `innerHTML`、`document.write` 或字符串模板；
- 禁止 `eval`、字符串 `setTimeout` 和不受控动态脚本；
- URL、重定向、下载文件名和富文本必须校验；
- 渐进改造应先隔离模块、增加测试和兼容层，不在一个小修复中整体迁移框架；
- 保留旧浏览器、插件和服务端模板的真实兼容要求。

## 六、传统前端专项复审

- 事件重复绑定、解绑、全局变量和插件生命周期；
- Ajax 回调、竞态、同步阻塞和错误恢复；
- JSP/模板转义、XSS、编码和后端契约；
- Layui 表格/表单/弹层状态；
- 静态资源缓存、加载顺序、旧浏览器和渐进兼容；
- 是否为局部问题引入了不必要的框架重写。
