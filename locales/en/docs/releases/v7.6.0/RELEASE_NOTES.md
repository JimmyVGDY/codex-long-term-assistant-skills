# V7.6.0 Release Notes

V7.6.0 introduces an external capability index and optional workflow gates. Development Skills search existing modules, check semantic compatibility, permissions, state, performance, test burden and maintenance cost, then record justified reuse or independent implementation.

The index stores bounded source locations and verification facts outside the repository, supports initial and incremental scans, and never approves business reuse from a matching fingerprint alone. Project gates are disabled by default. Explicit enablement adds pre-edit preparation and current finish checks; cold local exemptions cover only one existing file.

The frozen eleven-release Codex compatibility window is unchanged. Upgrade from 7.5.1 uses the existing transactional installer. No business project is automatically enabled and no stable memory is promoted.
