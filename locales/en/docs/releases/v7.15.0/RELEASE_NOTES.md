# V7.15.0 Release Notes

V7.15.0 introduces script-first GPT-6 routing for new Codex Desktop tasks. Reviewer, Worker, and Explorer share nine Luna, Sol, and Astra profiles at low, medium, and high effort. Missing optional evidence defaults to Sol/medium. Existing V3/V4/V5 roots retain their original replay contracts.

- Scripts collect scoped facts, calculate planning weights and shared budget holds, and issue exact dispatch permits. File and line counts are scope signals, not proof of difficulty or defects. Model suggestions remain bounded and require a new controller decision.
- Missing qualification cards, gain cards, historical samples, or optional material remain UNKNOWN with a safe next action. Confirmed identity, permission, budget, or integrity failures restrict the affected action. The optional file gate stays enabled and offers supervised `apply_patch` for legacy write attempts.
- A separate journal records preparation, atomic reservation, native creation receipts, terminal observations, and proven non-starts. Transient retries remain bounded by attempts, budget, and time; unknown terminal state resumes the same handle.
- Only unambiguous direct choices from native user prompts can select a profile above the ordinary adjustment range. Negation, quotations, and code examples do not elevate provenance, and raw prompts are not saved. New-task review and repair receipts are isolated per root and aggregate every report; missing reports, stale baselines, and unresolved conflicts remain unverified.
- A versioned same-chat handoff preserves unresolved research attempts and late-event ownership without inventing success or refunds. Standalone CLI adaptation remains outside the supported product surface.

This document describes a V7.15.0 source candidate. Installation, a fresh Desktop process, real model calls, commit, push, CI, tag, assets, and public release each require separate readback before being reported as complete.
