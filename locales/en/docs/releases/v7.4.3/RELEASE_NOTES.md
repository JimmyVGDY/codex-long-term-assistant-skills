# V7.4.3 Release Notes

V7.4.3 removes host runtime model identity and reasoning effort from Agent inputs, evidence, accounting, review, Evolution, and release gates. Automatic dispatch persists only an abstract approved profile, permit reference, reserved units, and outcome attribution.

TaskOutcomeEvent V3, DelegationBudget V2, and Reviewer result V4 are the current contracts. Event V2 and Budget V1 remain verifiable read-only and are exposed only through a safe allowlisted projection; current and legacy chains cannot be mixed.

The Codex CLI 0.153.2 frozen compatibility window is unchanged. Windows account-level transactional reinstall, Plugin readback, and installed-Hook lifecycle sealing passed. Remote CI, tag creation, and public Release publication are not pre-claimed by this candidate document.
