# Python Backend and AI Engineering

1. Establish Python, framework, ORM, driver, lock-file, packaging, worker, and deployment versions.
2. Separate synchronous I/O, asynchronous I/O, CPU-bound work, and GPU-bound work. `async def` does not prove a non-blocking call chain.
3. Check event-loop blocking, unbounded concurrency, missing awaits, session lifecycle, multi-worker state, task idempotency, cancellation, recovery, and timeouts.
4. Use `Decimal` for monetary values and explicit time zones for datetimes.
5. Combine engineering delivery for behavior changes; combine data infrastructure for storage, caches, messaging, RAG, GPU, or deployment; combine observability for traceback and worker evidence.

Use Luna for bounded discovery, Terra Medium for async and multi-worker reasoning, and Terra High only for complex concurrency, GPU scheduling, RAG authorization, or irreversible data processing. Long-running reliability must not depend only on in-process background tasks.
