# Java Backend Engineering

1. Establish Java, Spring, Servlet or Jakarta, dependency, build, and runtime versions from current evidence.
2. Read the complete target context, callers, configuration, data contracts, and directly related tests.
3. Keep Java 8 code free of Java 9+ syntax and APIs. Use `BigDecimal` for monetary values.
4. Check transaction proxy boundaries, connection and thread pools, idempotency, resource release, serialization, authorization, and hot-path cost.
5. Combine engineering delivery for behavior changes; combine data infrastructure for databases, caches, messaging, storage, or containers; combine observability when runtime signals are primary evidence.

Use Luna for mechanical location and bounded scans, Terra Medium for ordinary multi-file reasoning, and Terra High only for transaction, concurrency, access, core state, or financial consistency risk. Skill activation never grants Git, deployment, production, or data-write authorization.
