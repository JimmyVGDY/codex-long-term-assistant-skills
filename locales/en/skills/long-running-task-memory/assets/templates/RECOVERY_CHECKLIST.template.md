# Post-Compaction Recovery Checklist

- [ ] Read the current request and authorization
- [ ] Read global and project-level `AGENTS.md`
- [ ] Read `PROJECT_CONTEXT.md`
- [ ] Read `CURRENT_TASK.md`
- [ ] Read the current phase in `PLAN.md`
- [ ] Read the three most recent checkpoints in `PROGRESS.md`
- [ ] Follow references to relevant ADRs and Reviewer reports
- [ ] Check the current branch, HEAD, and baseline
- [ ] Run `git status`
- [ ] Inspect `git diff`, `git diff --stat`, and untracked files
- [ ] Confirm whether previous test results remain valid
- [ ] Reread the core code, configuration, and tests involved in the next action
- [ ] Confirm documentation and actual state do not conflict; if they do, write a "state divergence checkpoint"
- [ ] Confirm the single next action and current authorization before continuing
