# 历史 GitHub Release 页面

English: [GITHUB_RELEASES.en.md](GITHUB_RELEASES.en.md)

V1.0.0 至 V6.6.0 的 GitHub Release 页面对应公开脱敏重建标签，不是原始开发过程的实时发布记录。

- 每个页面同时提供中文和英文说明。
- 页面只建立标签、原始档案摘要、公开树摘要与脱敏计数之间的可追溯关系。
- 历史原始 ZIP 仅保存在本地，不上传为公共附件。
- 历史页面有意保持零附件；V6.6.1 及后续正式双语发行使用独立的可复现构建与来源证明链路。
- 页面创建时间是公开仓库整理时间，不代表相应版本最初形成的时间。
