# Historical GitHub Release pages

Chinese: [GITHUB_RELEASES.md](GITHUB_RELEASES.md)

The GitHub Release pages for V1.0.0 through V6.6.0 correspond to sanitized reconstructed tags. They are not contemporaneous records of the original development process.

- Every page contains separate Chinese and English sections.
- A page establishes traceability among its tag, original archive digest, public-tree digest, and sanitization count.
- Historical original ZIP archives remain local and are not uploaded as public assets.
- Historical pages intentionally contain zero assets. V6.6.1 and later bilingual releases use a separate reproducible-build and provenance pipeline.
- Page creation time records public repository curation, not the time when the corresponding version was originally produced.
