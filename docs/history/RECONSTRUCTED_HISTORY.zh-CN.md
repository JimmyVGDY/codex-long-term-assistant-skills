# 历史重建声明

本仓库的 V1.0.0 至 V6.6.0 历史于 2026-08-31 根据本地保存的正式发布 ZIP 重建。

- 这些提交不是当年的原始开发提交，也不表示当年的真实开发顺序。
- 重建提交按 Skill、Reviewer/Agent、Runtime/Hooks、安装脚本、测试、文档和发布元数据等可解释边界拆分。
- 提交和标签时间是历史重建时间；原始文件时间只作为档案证据，不作为 Git 提交时间。
- 每个版本标签表示该版本完整的公开脱敏快照。
- V3.0.0、V3.1.0、V3.2.0 中验证脚本里的个人目录示例已替换为中性测试目录。
- V4.0.0 至 V4.2.0 中与 Codex 无关的共享模板分支和外部参考已从公开树移除。
- 原始 ZIP 保持不变并仅保存在本地，不进入 Git，也不作为公开 Release 资产上传。
- `RELEASE_ARCHIVES.md` 记录原始 ZIP SHA-256、公开树摘要和脱敏计数。

本仓库采用 Apache License 2.0。历史重建不能替代对第三方依赖或引用材料各自许可证的遵守。
