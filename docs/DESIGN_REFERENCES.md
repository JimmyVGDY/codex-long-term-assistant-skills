# V4.1 设计参考

V4.1 没有直接复制外部文章内容，而是将以下公开资料和用户确认的运行时事实转化为可执行规则、状态工具、结构化协议和验证用例。

## 参考资料

- 用户提供的讨论帖：https://x.com/riba2534/status/2082916383248252976
- OpenAI Harness engineering：https://openai.com/index/harness-engineering/

## 落地原则

1. 给 Agent 一张稳定地图，而不是把所有规则堆进单个超长提示词；
2. 将状态、证据、门禁和恢复流程实现为可运行工具；
3. 子 Agent 使用独立上下文处理高噪声工作，只向主 Agent 返回结构化结果；
4. 独立上下文、工具限制和系统权限隔离分别记录，不能互相冒充；
5. 通过路由回归、语义校验、证据指纹和安装 doctor 建立反馈回路；
6. 当 Agent 反复失败时，优先补齐工具、文档和可验证边界，而不是单纯增加提示词。
