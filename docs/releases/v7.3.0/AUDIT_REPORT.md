# V7.3.0 审计报告

English: [AUDIT_REPORT.en.md](AUDIT_REPORT.en.md)

## 当前结论

V7.3.0 行为改动与发行差异按数据契约、测试交付两个独立逻辑只读视角复审；最终发行只接受集中去重后的结论。Reviewer 结果合同、最低档位门禁、归因最终化、成本 unknown 语义、Plugin 运行时选择、版本元数据、双语制品和升级路径均纳入范围。

当前实现保持 fail-closed：低于最低档位的 Reviewer 结果不能正常关闭；Reviewer 不能自行最终化归因；缺失成本不能参与低收益判断；Plugin 模式不能回退到历史 standalone runtime；真实校准样本不足时不能自动改写默认路由。`execution_authorization=NONE` 与 Terra High 自动上限未变化。

第一轮复审识别出四个集中根因：控制器未递归校验校准结果、未最终化成本进入收益分母、安装状态缺失或损坏时可能选择旧 runtime，以及升级文档遗漏 7.2.0。修复后，控制器在任何状态或台账写入前拒绝敏感嵌套字段和非字符串证据；收益指标只使用已最终化成本，同时保留观测总成本；已安装 Plugin 在状态或绑定缓存不可用时失败关闭；中英文升级清单均明确包含 7.2.0。第二轮定向复审是公开发布的硬门禁，只有无剩余阻塞项才继续。

复审属于逻辑只读而非系统只读：父会话拥有工作区写权限，Reviewer 通过明确的只读职责约束工作。该结论覆盖代码、文档、测试和本机安装；提交、推送、标签、公开发布与下载后制品核对仍是独立状态，必须逐项读回。

## 审计范围

- Reviewer packet/result/state schema v3/v3/v5 兼容与旧 v2 结果读取
- `minimum_acceptable_profile`、`INLINE/DELEGATE` 追加决策和预算边界
- finding 处置、归因最终化、去重校准台账与 `profile-weight-v1` 成本
- 缺失成本、未最终化归因、样本不足和默认路由不变门禁
- Plugin 与 standalone 运行时选择、安装状态绑定和缓存缺失失败关闭
- 7.3.0 当前版本元数据、双语发行、历史证据隔离和 7.2.0 升级路径

历史 `docs/releases/v7.2.0` 及更早目录保持原样，不作为 7.3.0 当前验收结论。
