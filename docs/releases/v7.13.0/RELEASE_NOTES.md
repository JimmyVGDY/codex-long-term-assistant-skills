# V7.13.0 发行说明

本版本将型号定位、思考强度收益和预算审批分开处理。产品仅支持 Codex Desktop；内部脚本继续用于安装、管理和验证。

- 显式 V4 目录涵盖 GPT-5.6 Luna/Terra/Sol 与 GPT-6 Luna/Sol/Astra 的 Low/Medium/High，共 18 个评测组合；GPT-6 九个组合按场景取得生产资格后才可启用。
- 同型号升思考档与跨型号切换使用直接配对收益证据。保留后续审查与返修资源，防止当前一次派发耗尽后续必要额度。
- 新增 Budget V4、Review State V9、Result V6、Sample V4，以及评测、发布、撤销、观察读回入口。
- 旧策略、账本与结果保留冻结解释器，5.6 继续服务明确兼容路径。没有资格数据时返回 CALIBRATION_REQUIRED，不自动替换既有任务。
- 安装器分开核验桌面管理组件与任务运行契约；移除独立 CLI 版本矩阵的发行依赖。组件的内部预发布号不再被误当作桌面能力结论。
- 发行暂存区将 Windows 启动脚本统一为 CRLF，消除不同 Git 检出方式导致的发行包差异；不改写源文件或冻结账本。

当前为实施候选。本地包验证、受影响检查、独立意见归并及候选安装读回已有证据；后续打包修复单独验证。原生 V4 门禁尚未通过：配置已显示受信，既有任务仍未产生预算预占与创建回执，新桌面任务验收正在进行。模型资格与公开发行仍未完成，不能只凭信任状态宣布通过。具体证据见[验证报告](VALIDATION_REPORT.md)与[复审报告](AUDIT_REPORT.md)。
