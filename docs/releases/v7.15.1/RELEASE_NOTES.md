# V7.15.1 发行说明

新任务默认采用 GPT-6 Luna、Sol、Astra 的 low/medium/high 九档。脚本计算事实、选型、共享预算、预占、必需预留和重试；模型保留语义判断与有界调整。缺少可选证据时使用默认或降级路径，不关闭门禁、不补造通过。5.6 与旧账目保留显式兼容，主会话选择保持不变。

本版同时细化指标口径、必需能力约束、预留转换、未创建重试与工作项调整谱系，并从现有账本生成不会触发额外调用的自然观察。质量和实际费用缺少可靠来源时保持未知。

V7.15.1 修复同一聊天中新 G6 子任务被旧 V5 Context Hook 错误拦截的问题。新根先按版本化归属判断，旧根继续使用原门禁。

原生 SubagentStop 可能早于 task_complete。若已有可信最终消息，控制器将该调用结算为 UNKNOWN，保留已消耗尝试和规划单位，不猜测 PASS、不退款；重复 Stop 幂等。原生最终消息的 final_answer 形态可供复审投影读取。

V7.15.0 已安装缓存与原始失败证据保留。此源码候选的安装、真实 Desktop 验证、提交、推送和公开发布各自独立核验。
