# V7.17.0 Release Notes

This release uses official v7.16.2 as its functional baseline. It adds six Skill quality workflows and addresses unnecessary blocking in task budgets, artifact paths and audit recovery. The [public release](https://github.com/JimmyVGDY/codex-long-term-assistant-skills/releases/tag/v7.17.0), six anonymous downloads and official payload/installation checks were verified. Effective-behavior claims remain limited to recorded native calls.

- Artifact evaluation freezes rules and synthetic inputs, checks protected files, assertions and comparability, and provides escaped HTML, bounded PNG previews and traceable feedback.
- Documentation and frontend guidance add independent reader tests, design briefs, rendered checks and browser acceptance while reusing existing templates and design systems.
- Routing and MCP guidance add 24 grouped routing cases, development/final splits and repeated observations, plus contracts, pagination, composed queries, errors and permission cases.
- Task budgets register independent objectives within one chat. Repairs, continuations, renaming and subagents retain the original ledger; late events keep their original owner.
- Execution allowances reuse the root for Workers/Explorers while preserving Reviewer restrictions. The new journal format retains historical prefixes and reserves bounded storage for authorized attempts and settlement.
- Native requests freeze explicit external artifact scopes. Missing post-write audit evidence leads to readback and recovery, without claiming that files were not written or requiring a restart.

Actual permissions, identity, credentials, links, paths, journal integrity and budget limits remain protected. Semantic task classification is coordinator policy. Logical-readonly does not mean system isolation, and planning units are not actual charges.

See [task budgets](../../operations/task-budget-scope.en.md), [artifact scopes](../../operations/artifact-scope.en.md), [gate recovery](../../operations/gate-recovery-policy.en.md), [artifact evaluation](../../SKILL_ARTIFACT_EVAL.en.md), the [validation report](VALIDATION_REPORT.en.md) and [audit report](AUDIT_REPORT.en.md). Codex Desktop is the sole product target.
