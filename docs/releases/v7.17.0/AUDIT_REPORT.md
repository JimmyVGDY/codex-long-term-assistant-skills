# V7.17.0 候选审计报告

用户明确要求六项 Skill 优化及追加门禁修复全部实施，终点包含提交、推送和公开发行。功能基线为官方 v7.16.2。计划、测试结果与优化 Proposal 不产生新的操作授权。

## 授权与隔离

- 产品仍只支持 Codex Desktop。公开合成输入与任务产物用于本轮验收，原始记录位于仓库外；不新增默认业务正文采集、生产账号或独立模型命令行产品。
- 预算按独立目标登记。修复、续跑、拆分、改名和子 Agent 保留原根；控制器、在途调用及迟到事件固定归属。Worker/Explorer 与 Reviewer 追加分别约束角色、档位和范围。
- 真人明确更正先前拒绝时恢复同一申请及额度桶，保留旧决定与全部消耗；同时间戳以原生字节顺序消歧。引用、工具输出、普通附和和手工证明不能批准。
- 协调者在既有直接用户授权内，核验真实父子关系、原生请求及精确目标后登记子 Agent 产物范围。登记不改变宿主文件权限；凭据、控制目录、其他项目、链接、路径逃逸和身份冲突保护保留。
- 独立任务采用逻辑隔离；Reviewer 仅能按实际证据称逻辑只读，不冒充系统只读。

## 恢复与证据

未知状态描述证据边界。写后回执缺失不等于文件未写入，也不自动要求重启；允许继续、实际副作用与验证通过分别记录。旧读取器拒绝的报告、原生错误、格式失败和已发生费用均保留，不改原文、不清账，不为没有新信息的同包重复派发。

并行工具读取暴露的账本锁竞争已作最小修复：锁内捕获完整事件，锁外完整校验；写入方继续持锁重验。原生失败、同账本副本的修复前后复现及 79 项定向测试分别留证。未把局部成功推广为所有宿主路径均受强制控制。

候选 12 的安装状态和账户/缓存摘要已读回，安装 verify 通过。原安装输出解码异常仍保留，未重复安装，Desktop 未重启。新增账本事件要求匹配读取器；回滚必须保留可读取完整历史的运行时。旧写后审计缺口不追溯填为 PASS。

## 收尾边界

80 次冻结路由已全部执行，但有效报告与路由判断均有失败；原描述保留，收益 UNKNOWN。前端的五组、20 张原图已获独立 Agent 实际观察；安全与状态复审未发现可行动问题。交付原报告的 `PARTIAL` 枚举不合规，机器状态仍为 UNVERIFIED；表单页眉意见经冻结初始文件哈希核对被驳回，未改写样例或原报告。MCP 答案通过不抹除客户端错误与自有进程清理记录。具体计数和 CI 基线见[验证报告](VALIDATION_REPORT.md)。

本轮独立复审已执行并保留协议限制，当前材料用于发行收尾，不声明已经正式发布。提交、推送、矩阵验证、制品、安装、原生调用、重启及公开发行分别读回；真实费用与可推广收益未知，规划单位不是实付金额。
