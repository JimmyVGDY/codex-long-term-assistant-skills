# V7.13.4 发行说明

V7.13.4 修复 Codex Desktop 在 Windows 上的安装权限与委派入口问题。产品仅支持桌面应用；既有稳定组件资料作为内部契约回归参考保留，不构成独立 CLI 支持范围或桌面版本准入条件。

- 安装公开 Plugin、Hook 与运行时载荷时继承目标父目录的读取权限，不额外授予写权限；私有状态与恢复副本沿用原规则。
- 排除生成的 Python 字节码，使公开运行目录与发布载荷一致。
- 统一裸名、点分名与桌面拼接式委派工具名，并在单个 Pre/Post 处理器组中登记完整名称，避免漏检和重复处理。
- 保留 Windows 路径身份与恢复保护、冻结 V3 默认和 GPT-5.6 兼容。GPT-6 九个候选组合继续受场景资格与真实证据约束。

实际桌面安装、普通沙箱读取与写入拒绝，以及 V4 消息重入拦截已验证。正向创建仍在执行前被 `V4_REQUEST_MESSAGE_MISMATCH` 拒绝：当前宿主传递不透明加密正文，尚无可核验的明文绑定方式。受控明文改写实验也出现解码错误，未纳入产品。本版本不绕过校验、不伪造回执、不启用 GPT-6 默认，不宣称模型资格或正向原生准入通过。

包内保留 0.157.0 至 0.153.0 的既有内部组件契约样本及官方制品、源码摘要。这些记录不是桌面应用的支持版本窗口；实际宿主仍需按运行中的桌面组件单独验收。

提交、推送、安装、CI、标签、Release、资产、provenance 与公开生效分别读回。完整模型性能、思考强度收益及默认迁移仍属于后续未完成工作。
