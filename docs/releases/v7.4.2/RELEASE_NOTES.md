# V7.4.2 发行说明

版本：7.4.2  
宿主窗口：Codex CLI 0.153.2 与此前十个稳定发行版

## Codex 0.153.1 / 0.153.2 变化

- 0.153.1 让 Guardian 的 computer-use 评分服从当前模型的 `node_repl_auto_review_required`，切换模型时使旧评分失效，避免沿用不再适用的判断。
- 0.153.1 在宿主目录中加入 API 支持但默认不展示的 GPT-6-Astra 配置，并引入 `unified_exec` 接口；默认模型、模型选择器和本项目自动路由均不因此改变。
- 0.153.2 只把 Fast 档说明从 1.5x 更新为 2x，属于展示文本变化，没有新的 Plugin、Hook 或配置契约。

## 本包适配

- 将闭合兼容注册表锚点推进到 0.153.2，活动窗口固定为 `0.153.2`、`0.153.1`、`0.153.0`、`0.152.1`、`0.152.0`、`0.151.0`、`0.150.1`、`0.150.0`、`0.149.1`、`0.149.0`、`0.148.0`。
- 固定 0.153.1/0.153.2 官方 npm tarball、SRI、SHA-256、CLI help 和 Plugin JSON 摘要；退出活动窗口的 0.147.0/0.146.1 只保留在 V7.4.1 历史证据中。
- 增加模型切换后的证据失效回归，以及 `unified_exec` 不消耗子 Agent 派发许可或预算的回归。
- 升级安装器、双语清单、可复现构建、验证脚本和 GitHub Windows/Ubuntu 11 单元矩阵到 V7.4.2。

## 不变边界

- 不自动启用 GPT-6-Astra，不改变 Luna/Terra 路由、权重、Terra High 上限或 Proposal 的 `execution_authorization=NONE`。
- `unified_exec` 不是子 Agent 派发入口；真正的 `spawn_agent` 仍必须经过显式 permit 与根任务预算门禁。
- 普通 Hook 字段不构成可信实际模型证明；未登记的未来版、预发布版与窗口外版本继续失败关闭。

## 当前证据状态

0.153.1 与 0.153.2 的 Windows 隔离 CLI、Plugin 往返、合成 Hook 和官方制品校验已经通过。全 11 单元、Ubuntu CI、真实账户、独立复审、标签与公开 Release 必须在最终验证报告中单独读回，不能由本说明预先宣称。
