# V7.15.0 发行说明

V7.15.0 为 Codex Desktop 的新任务启用脚本决策 GPT-6 路由：Reviewer、Worker、Explorer 共用 Luna、Sol、Astra × low/medium/high 九档。资料不足时使用 Sol/medium，既有 V3/V4/V5 根继续按原合同回放。

- 量化的范围事实、型号权重、共享预算、未来必需预留和派发许可由脚本计算；文件与行数是范围信号，不是难度或缺陷证明。模型可提出有界调整，实际参数须由 Hook 按当前账本重新核验。
- 缺少资格卡、收益卡、历史样本或可选材料时保留 UNKNOWN 并继续可行工作；已确认的身份、权限、预算和完整性问题只限制对应动作。原可选文件门禁保持开启，旧式写入给出受监督 `apply_patch` 路径。
- 新账本区分准备、原子预占、宿主创建回执、原生终态与无启动证明；瞬时重试受次数、余额和时间共同约束。终态未知时续查同一调用。
- 仅从原生用户提示中识别无歧义的直接型号与强度选择；否定语句、引文和代码示例不会提升权限，也不保存原始提示。新任务的复审与返修结果按根隔离、聚合全部报告，缺报告、旧基线和未裁决冲突维持未验证。
- 同一聊天的旧研究根通过版本化交接保留未结项与迟到事件归属，不补造结果或退款。独立脚本的 CLI 产品适配仍不在支持范围内。

此文档描述待验收的 V7.15.0 源码候选。安装、Desktop 新进程效果、真实模型调用、提交、推送、CI、标签、资产和公开 Release 分别读取证据；没有证据时不记为完成。
