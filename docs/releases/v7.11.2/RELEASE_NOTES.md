# V7.11.2 发行说明

V7.11.2 是 Codex CLI 稳定版兼容补丁，目标为官方稳定版 0.155.1。该版本的唯一上游行为变化是：本地 TUI 默认不再发送 reasoning summaries，避免不支持该字段的提供方拒绝请求；显式配置仍保持生效。

## 变更

- 冻结窗口更新为 `0.155.1`、`0.155.0`、`0.154.0`、`0.153.4`、`0.153.3`、`0.153.2`、`0.153.1`、`0.153.0`、`0.152.1`、`0.152.0`、`0.151.0`。
- 登记官方 npm integrity、tarball SHA-256、`rust-v0.155.1` 标签 commit 与 Hook/apply_patch 源码摘要。
- 保留 Plugin、Marketplace、Operation v2、十档 Reviewer、预算与旧账本重放行为；未来版、预发布版和窗口外版本继续失败关闭。
- 支持从 V7.11.1 及 manifest 已声明的旧版本升级。

Git 提交、标签、GitHub Release、账户安装和实际生效是独立事实，必须分别读回。
