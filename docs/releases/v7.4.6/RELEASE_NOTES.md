# V7.4.6 发行说明

版本：7.4.6
主题：Codex CLI 0.153.4 稳定版兼容
宿主窗口：Codex CLI 0.153.4 与此前十个稳定发行版

## 上游变化

- OpenAI Codex CLI 0.153.4 修复 GPT-6-Astra 在内置模型选择器中的可见性，并在未显式选择模型时将其作为内置默认。
- 异步提问说明现在仅在宿主提供相应提问工具时适用。
- 这些变化不修改本包已冻结的 Plugin、Marketplace 或 Hook 合同，因此本次推进兼容窗口而不重构协议。

## 本包变化

- 将闭合兼容注册表锚点推进到 0.153.4，窗口固定为 `0.153.4`、`0.153.3`、`0.153.2`、`0.153.1`、`0.153.0`、`0.152.1`、`0.152.0`、`0.151.0`、`0.150.1`、`0.150.0`、`0.149.1`。
- 固定官方 npm tarball、SRI、SHA-256、CLI help 与 Plugin JSON 证据；0.149.0 退出活动窗口但保留在历史报告中。
- 更新 Windows/Ubuntu 兼容矩阵、安装器、发布验证、双语文档与站点索引到 V7.4.6。
- 自动子 Agent 的批准档位仍仅限 Luna/Terra；GPT-6-Astra 的上游默认变化不扩大自动路由策略。

## 本地证据边界

- Windows 原生 CLI 已由同一 npm 全局通道从 0.153.3 更新到 0.153.4，版本、帮助、登录状态和 Plugin 列表读回通过。
- 0.153.4 官方制品校验、隔离 CLI、Plugin add/list/remove 往返与合成 Hook 已通过。
- V7.4.6 账户级事务安装、`verify`、`status`、`doctor`、Plugin 激活和源码/Marketplace/cache 三方 182 文件 payload 摘要一致性已通过；可恢复备份已保留。
