# V7.17.3 发行说明

- 细分桌面客户端更新、管理合同变化和探测不可用，避免把正常组件更新诊断为安装损坏；运行验收证据仍需单独核验。
- 首次从无 Git 目录进入项目时，依据宿主登记的原生回合确认当前工作区，按项目保存来源 v2 与审批游标 v2；旧来源、原任务根、已用额度和迟到回调归属保持不变。
- 父会话、子任务身份和审批绑定统一处理经过同实体核验的账户根目录联接，修复 Windows 账户迁移后 `V5_REPARSE_PATH_DENIED` 误拦截；会话内部链接、其他账户目录、文件替换和跨项目输入继续拒绝。
- 修复 Windows 来源记录读写与原子替换竞争，限制长会话回读窗口；自动续跑上下文不能充当人工批准。
- 内部稳定组件合同窗口推进到官方 0.164.0 及此前十个稳定发行版，冻结官方制品和源码摘要；产品支持范围仍为 Codex Desktop。

本轮实际验收目标为 Codex Desktop 26.1023.50603 / build 22391，内部组件 0.165.0-alpha.1.2。已验证所列原生读取、审批恢复、取消、同工作安全回退和账户安装路径。客户端待重启更新后的新版本尚未验收，未执行重启。密文原任务直接续跑保持拒绝，由脚本安排同工作范围的新调用安全回退。

包验证、独立源码复审、实际运行及公开发布分别记录，详见[验证报告](VALIDATION_REPORT.md)和[审计报告](AUDIT_REPORT.md)。
