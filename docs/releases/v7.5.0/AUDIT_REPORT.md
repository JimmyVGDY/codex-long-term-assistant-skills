# V7.5.0 审计报告

范围为任务反馈、观察健康、有效增量、优化假设、收益生命周期、回归候选与跨账本校准，以及双语交付。一次实施前审查、两轮实施后审查，共 5 次批准的 Terra Medium 派发；均为逻辑只读，不宣称系统只读或宿主预算预占通过。

确认并修复：linked worktree 身份解析；已有任务新增合格异常信号的触发；收益样本排除实施任务；小样本统计临界值；去重前原始输入上限；回归跟踪的引用重放与结果重算。六项集中修复均获定向复核通过。

同一项目/仓库/会话/轮次/任务仅允许一份不可变定稿。定稿后工作区变化需要新轮次，避免观察器面对多个冲突终态；文档与测试已覆盖，复核认可该契约。

旧事件和旧提案链保持只读兼容。默认/显式策略一致。每条校准样本先校验所属账本，再按同项目、同仓库、角色、职责、难度、风险和上下文比较；保留独立任务数量与不确定区间。收益为观察性证据，不作因果保证。

自动化可采集最小元数据、检查、比较和准备候选；不会自动接受或实施提案、修改业务代码/Skill/AGENTS/路由、部署或跨项目晋升知识。实施验证 PASS 与收益 SUPPORTED 分开记录。

测试与安装边界见 [验证报告](VALIDATION_REPORT.md)。远端发行状态由发布工作流与附件独立证明。
