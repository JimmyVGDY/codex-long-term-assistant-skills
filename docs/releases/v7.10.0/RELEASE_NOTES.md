# V7.10.0 发行说明

V7.10.0 完成 P1-P2 使用体验改进：基础安装在未启用可选增强时不再被误报为降级；状态/诊断按能力区分影响范围并提供结构化下一步；新增四条日常路径、统一入口和只读 `resume` 恢复摘要。

本版本还提供显式 UX 基准采集、白名单聚合导入和前后比较。基准不启动模型、不上传数据，也不能单独证明真实 Agent 任务提速。

同时修复 Windows PowerShell 5.1 基础安装复制隐藏目录时的目录/文件混淆；受控递归复制后，基础 Marketplace、十个 Skill 和原生 Plugin 注册可正确读回。

发布、安装、注册、当前任务加载、真实新进程验收和 Desktop 会话生效属于不同证据层；最终状态以本版本工作流、制品校验和交付记录为准。
