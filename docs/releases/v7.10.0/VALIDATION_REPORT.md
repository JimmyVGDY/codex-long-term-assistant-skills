# V7.10.0 验证报告

本报告记录 7.10.0 修复候选在 2026-09-15 的本地证据。发布完成以目标提交的 CI、正式 Release、下载回验及发布后记录为准；本文件不单独证明发布或当前账户生效。

已通过的定向验证：41 项状态/诊断测试、8 项基准工具测试、26 项恢复及子进程资源测试（Windows 链接权限导致其中 2 项跳过）。恢复测试覆盖与旧算法相同的完整快照、源码变化后的 STALE、完整过期查询在两条入口均返回 0、未使用的文本转换器、实际适用转换器不执行、总读取预算、身份冲突和文件字节不变性。状态测试覆盖正常基础安装、停用、未知、重复注册、强制控制失效、事务优先级、采样变化和有界 journal 读取。

完整验证的上一轮进入 228 项 runtime 测试后发现 2 项恢复失败；根因是把系统中未应用到变更文件的文本转换器也判为阻塞。问题已修复，以上定向回归通过；修复后的完整包验证仍须重跑。不得沿用修复前包、ZIP 或验证报告的摘要。

双语来源及生成投影检查、严格本地化审计、1,123 个仓库内部链接检查通过。文档站导航已统一为 V7.10，最终站点构建和远端 Pages 仍需绑定最终提交。

独立复审采用逻辑只读方式。本轮发现的事务动作优先级、读取错误变化和不存在的基准输入三项问题已集中修复并通过定向反例；最终差异、修复记录及复审结论保存在仓库外，发布前需完成关闭与绑定。

隔离原生 Codex 0.154.0 已通过认证、十个 Skill 发现及真实模型/终端工具预检。验收使用本机原生 app-server 的内存令牌认证，凭据不复制、不落盘；这是私有验收路径，不是向所有宿主承诺的新产品接口。旧版与候选的三类真实任务各三个样本、20 对包装层测量、最终 ZIP 安装矩阵和公开前真实验收分别记录。失败、超时和未知样本保留，不以进程退出替代外部 Oracle，不由小样本声称普遍提速。

当前真实账户升级与 Desktop 重启不在本轮执行范围。安装文件、Plugin 注册、新 CLI 进程加载、任务行为、Desktop 当前会话与业务项目生效分别举证。

`RELEASE_COMPLETE` 与 `INCIDENT_EFFECTIVE` 分别判断：前者表示本轮发行及发布后验证全部完成；后者还需具体事故现场的业务生效证据。当前本地或隔离验收不能替代其中任何尚未取得的证据。
