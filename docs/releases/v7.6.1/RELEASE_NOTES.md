# V7.6.1 发行说明

本次补丁修正文档维护与发行来源边界。

- 区分六事件观察链与七个 Hook 入口，修正迁移版本、预算所有者及格式说明。
- 英文来源统一到 locales/en，通过目录清单生成同级英文呈现，增加事实与漂移检查。
- 当前指南、配置/恢复和架构建立稳定路径，旧路径保留章节与兼容入口。
- 发行只收集 Git 受管文件；无 Git 构建使用带内容哈希的显式源码快照，双语覆盖使用同一捕获来源。
- 历史任务、缓存和旧产物按校验清单外置，当前 Profile、索引和项目可选门禁绑定保持原位置。

升级沿用已有安装/恢复入口，支持从 V7.6.0 升级。组件复用门禁默认关闭行为、数据格式与兼容窗口不变。
