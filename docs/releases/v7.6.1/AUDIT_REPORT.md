# V7.6.1 审查记录

范围：当前文档事实、英文来源、兼容目录迁移及发行源码捕获。以现行代码、配置和本地验证为依据；不将全局核心规则修订号、包版本与数据格式版本混为一谈。

源码捕获实施后独立复审发现两个非阻塞问题：Git 输出大小事后检查、异常清单结构未经校验。集中修复为有界流式读取及显式清单结构校验，补充定向用例；第二轮对该范围复核通过，无新增发现。Reviewer 为逻辑只读。其后文档事实与测试隔离修订采用定向验证，不冒充整个最终工作区均经过同一轮独立复审。

文档目录清单管理当前、参考、历史和生成内容；英文权威源为 locales/en。首批目录迁移保留旧入口及章节，未重排运行时、公共 CLI 和 Skill 路径。源快照清单证明所列内容哈希，不单独证明可信发布者身份；正式发布另由干净提交、CI 和来源证明约束。

索引候选只提供定位证据，门禁流程通过不批准业务语义。未验证的宿主和平台不记为通过。首次完整包命令的两处失败、修复及复验结果见[验收记录](VALIDATION_REPORT.md)。
