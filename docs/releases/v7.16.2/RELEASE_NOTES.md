# V7.16.2 发行说明

本版本为复审额度追加与授权恢复提供完整入口，已于 2026-10-15 11:22:13 UTC [正式发布](https://github.com/JimmyVGDY/codex-long-term-assistant-skills/releases/tag/v7.16.2)。双语包、六个附件及公开下载均已核验；详细结果与边界见本版本验证和审计报告。

当任务可用规划单位或尝试次数不足时，控制器生成有范围的申请。用户批准后在原根账本追加专用分配，随后重建当前派发许可；基础模板与既有支出保持原样。

- 单位和尝试次数一并核算，已批准未使用的额度优先复用；并发占满及未知终态恢复原调用。
- 工作、角色、档位和路径范围共同约束消费；刷新审查包不清零计数，也不丢弃范围内的批准。
- 原生用户来源、重复响应、并发、崩溃恢复、撤销和关闭分别校验；截图、模型声明和工具输出不能批准。
- 新读取器安装一致后才写入扩展事件，保留旧 G6 前缀及冻结的历史解释器；中英文问题使用同一申请。

操作和回滚规则见[追加与恢复协议](../../../skills/multi-agent-independent-review/references/review-allowance-amendments.md)。验证与审计边界见[验证报告](VALIDATION_REPORT.md)和[审计报告](AUDIT_REPORT.md)。仅支持 Codex Desktop。
