# V7.16.2 验证报告

本报告定义本版本的验证范围与证据解释。具体候选的执行结果应绑定源码指纹，并保存在仓库外的包验证、独立复审及部署回执中；本文不代替这些结果，也不宣称公开发行。

## 定向回归

- `test_g6_allowance_budget`：原子消费、角色/档位隔离、旧前缀、未知调用、未启动重试、必需保留量和关闭后的结算。
- `test_g6_allowance_authority`：真实格式的隔离记录、人工来源元数据、直接与选项回复、引用拒绝、重复与并发、入账后中断、文件替换和大记录恢复。
- `test_g6_allowance_workflow`：真实脚本和 Hook 子进程串联耗尽、申请、批准、派发与回执；范围内刷新、范围扩张、重复申请、读取器升级顺序和账户运行库布局。
- 既有 G6、V3/V4 兼容、包安装、安全、隐私、文档与双语验证继续运行。

## 完整包与本机验收

完整检查使用声明的源码候选，保留工作区无副作用检查，核对载荷、链接、翻译、语义和全部包/运行时测试。忽略目录中的历史副本不进入正式源码快照。

本机验收分别核验已安装文件、Plugin 注册、实际执行的读取器、原生批准入账、Reviewer 创建及结果对账。隔离夹具不会替代真实用户批准或真实 Agent 调用，规划单位不代表实际费用。

## 证据边界

检查通过不能证明未执行的场景。没有当前聊天的原生预占和回执，不能将策略约束表述为宿主强制；没有实际公开读回，不能将候选包或本机安装表述为公开 Release。
