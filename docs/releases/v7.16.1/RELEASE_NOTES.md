# V7.16.1 发行说明

本版本修复 Codex Desktop 主任务在收到大型图片或其他工具结果时，被子任务上下文 Hook 误拒绝或提示返回未完成的问题。此前整个 Hook JSON 超过 2 MiB 就会在身份识别前失败。

- 大事件完整校验后，只依据顶层身份判断是否为主任务，忽略正文中的伪身份；字段顺序不影响判定。
- 保留小事件的原有解码路径、子任务 2 MiB 上限及 G6/V5 权限检查；缺省、null 和空字符串保持原有无子任务 ID 的兼容含义，非字符串或非空别名冲突拒绝。
- 流式解析不记录或写盘工具正文；传输最多 128 MiB，解析预算 3 秒，嵌套最多 64 层、值节点最多 262,144，键累计最多 1,048,576 字符，单个保留字符串最多 65,536 字符，数字词元最多 4,096 字符。超过资源边界或身份不明确时仍失败关闭。

仅支持 Codex Desktop。代码与测试、安装读回、真实宿主生效和公开发行分别核验，见[验证报告](VALIDATION_REPORT.md)及[审计报告](AUDIT_REPORT.md)。
