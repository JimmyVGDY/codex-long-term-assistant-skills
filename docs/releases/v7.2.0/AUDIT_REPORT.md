# V7.2.0 审计报告

English: [AUDIT_REPORT.en.md](AUDIT_REPORT.en.md)

## 当前结论

本地发布前审计已完成两轮逻辑只读独立复审，最终没有阻塞项。首轮 3 个 Reviewer 发现 8 组根因，定向修复了 schema 歧义、未知 Skill、覆盖率去重、部分证据持久化、`BaseException` 绕过、报告摘要绑定、脏文件二次变更和非有限浮点数；第二轮 2 个 Reviewer 又发现 3 组问题，修复了输出路径门禁时序、已跟踪删除和用例证据索引遗漏。

复审覆盖安装事务与 Marketplace schema、验证副作用门禁、宿主证据契约、演进信号判定、双语发行和历史证据隔离。所有发现均在稳定差异上集中修复并完成定向复核；未知 Codex 版本仍失败关闭，Proposal 的 `execution_authorization=NONE` 与自动模型上限未变化。

复审为逻辑只读而非系统只读：父会话拥有工作区写权限，Reviewer 依靠明确的只读职责约束。模型请求策略未越过 Terra High 上限，但宿主未提供可关联的实际运行模型证明。该结论只覆盖代码、测试和本机安装；提交、推送、标签、公开发布及下载后制品核对必须保持独立状态并分别读回。

## 审计范围

- Python 3.11/3.13 兼容契约和 Windows/Ubuntu CI 矩阵
- 安装、校验、回滚、Marketplace schema 与工作区零副作用边界
- 真实宿主路由报告的输入、输出、字节数和 SHA-256 绑定
- 受控演进的信号级证据充分性、唯一任务覆盖率和端到端持久化
- 7.2.0 当前版本元数据、双语发行、历史证据隔离和 7.1.0 升级路径
- Git 提交、推送、标签、草稿 Release、公开发布和制品核对的独立状态

历史 `docs/releases/v7.1.0` 及更早目录保持原样，不作为 7.2.0 当前验收结论。
