# V7.13.1 发行说明

本版本延续 GPT-6 兼容支持：产品仅支持 Codex Desktop，默认继续使用冻结 V3。六型号、十八个思考档组合可用于明确授权的评测；GPT-6 的九个生产候选仍须先通过场景资格、升档或换型号收益与资源审批。

- 恢复普通受管文件前，先核验备份是否存在且内容完整；备份损坏或缺失时保留当前文件并保留待处理事务。
- 子测试中的非断言异常同时保留既有 `SUBTEST_FAILURE` 和 `ERROR` 状态及固定异常类型。报告格式、异常白名单和敏感正文限制保持不变；状态计数可能重叠，应使用执行用例数统计测试数量。
- 保留 GPT-5.6 的兼容与对照路径，以及旧策略、账本和结果解释器。模型定位、思考强度收益与预算约束继续分别核验，不能仅按型号名称或价格档位自动升级。
- V7.13.0 标签作为未完成最终发行验收的候选保留，本补丁使用新的版本和标签。

本节点不启用 GPT-6 生产默认，也不宣称严格原生预算已经生效。真实派发、模型资格与实际消耗评测仍须完成。当前证据与边界见[验证记录](VALIDATION_REPORT.md)和[复审记录](AUDIT_REPORT.md)；公开发行以标签、附件及来源证明读回为准。
