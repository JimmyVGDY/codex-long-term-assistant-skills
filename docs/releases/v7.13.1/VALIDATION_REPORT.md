V7.13.0 发行流程出现的 Windows 间歇性子测试失败仍未确认原因。原顺序和正式前置环境的定向复现均通过，不能据此宣布原问题已修复。新分类保留后续正式验证中的异常类型；所有既有失败记录保留。

V7.13.1 首轮 Windows 3.11 检查明确记录了一个安装器用例的 `TimeoutExpired`，其他三个操作系统/解释器组合通过。已确认该异常来自测试封装的 30 秒等待；调整测试进程时限不会将失败转换为通过，后续仍须重新执行完整检查。本机首次整包验证的七项 PowerShell 入口失败另由默认脚本执行策略导致，使用专用验证进程的 `RemoteSigned` 后七项均通过；未更改账户级或系统级持久策略。
