# V7.1.0 审计报告

English: [AUDIT_REPORT.en.md](AUDIT_REPORT.en.md)

## 当前结论

本地发布前审计通过，未发现阻止提交的高风险问题。版本升级有实际依据：原安装器未接受 Codex CLI 0.152.1，旧账户工具安装还可能缺少 `cp_runtime.evolution` 依赖；7.1.0 同时修复这两个可观察行为缺口，并保留 0.150.1 的已验证兼容。

差异复核覆盖版本契约、安装事务与回滚边界、账户工具来源解析、payload 身份、双语发布面和历史证据隔离。未知 Codex 版本仍失败关闭，Proposal 的 `execution_authorization=NONE` 与自动模型上限未变化。

该结论来自主 Agent 在稳定差异上的隔离二次复核，不等同于独立 Reviewer。它只确认代码、测试和本机安装；提交、推送、标签、公开发布及下载后制品核对必须保持独立状态并分别读回。

## 审计范围

- Codex CLI 0.152.1 版本与 Plugin 命令/JSON 契约
- 0.150.1 已验证兼容保留和未知版本失败关闭
- 账户工具的安装、校验、回滚、卸载与受限任务回退
- 7.1.0 当前版本元数据、双语发行、历史证据隔离和 7.0.0 升级路径
- Git 提交、推送、标签、草稿 Release、公开发布和制品核对的独立状态

历史 `docs/releases/v7.0.0` 保持原样，不作为 7.1.0 当前验收结论。
