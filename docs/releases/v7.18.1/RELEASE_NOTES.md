# V7.18.1 发行说明

- 固定使用 Windows x64 与 Ubuntu 24.04 x64 均可安装的 Python 3.13.17，PR 阶段即核验两端的发行解释器。

- 健康的基础安装可安全复跑。安装器核对插件身份、版本和启用状态，中断恢复会保留用户文件。
- 项目可限时调整门禁的等待、退避和重试参数。写入结果未知时，助手核对原操作。账户目录迁移后，原任务和迟到回执按原账本恢复。
- 选择模型目录试点的项目可使用 GPT-6.2 Sol 和 Astra。候选按宿主能力、任务适配和预算选择。切回旧策略只影响后续新任务。
- 发布流程在签署前比对 Windows 和 Ubuntu 的中英文 ZIP。重复运行时核对同名版本、标签提交和六个附件，异常中断会保留草稿现场。

构建和实测范围见[验证报告](VALIDATION_REPORT.md)，独立复核与发布边界见[审计报告](AUDIT_REPORT.md)。
