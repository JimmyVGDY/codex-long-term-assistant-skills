# V7.13.3 发行说明

本补丁修复 Windows 桌面任务中普通路径与长路径表示指向同一目录，却无法找到既有预算绑定的问题。产品仅支持 Codex Desktop。

- 仅在文件系统证实目录相同时识别 Windows 路径别名，复用原登记与账本；保留历史指纹、事件及首次身份凭据。
- 绑定操作按真实任务加锁，等价路径存在冲突、身份核验不可用或登记消失时拒绝继续，防止建立第二个根或退回无预算状态。
- 生命周期身份关联在账本锁内比较已核验的等价证明，兼容并发与重复回执；同一语义身份沿用首个摘要。
- 仓库外状态及受管目录检查采用相同路径规则：保护根目录，并允许尚未创建的合法子目标。
- 保留 V7.13.2 的桌面管理组件兼容资料。冻结 V3 仍为默认策略，GPT-5.6 保留兼容与对照；六型号十八个评测组合及 GPT-6 九个生产候选的资格门槛保持不变。

路径修复通过不代表真实派发强制记账或模型资格已通过。完整验证、安装、原生回调、公开附件及来源证明分别验收，见[验证记录](VALIDATION_REPORT.md)与[核验记录](AUDIT_REPORT.md)。
